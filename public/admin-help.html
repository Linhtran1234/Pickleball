HỖ TRỢ BAN TỔ CHỨC

Lấy lại quyền truy cập.
Tiếp tục cùng giải đấu.

Việc tạo lại giải chỉ xóa dữ liệu thi đấu. Tài khoản, quyền và mật khẩu của Ban tổ chức được giữ nguyên.

01 Nếu vừa cài bản mới

Cài đặt mới tạo tài khoản khởi tạo admin, mật khẩu admin123. Đăng nhập rồi đổi mật khẩu trong Quản lý người dùng.

Nếu đã đổi mật khẩu, hãy dùng mật khẩu bạn đã đặt. Mật khẩu khởi tạo không thay thế mật khẩu của tài khoản đang có.

02 Nếu quên mật khẩu hoặc mất quyền Admin

Người quản lý máy chủ mở terminal tại thư mục ứng dụng, dừng server rồi chạy:

npm run admin:recover

Nhập tên tài khoản cần khôi phục (mặc định admin) và mật khẩu mới ít nhất 8 ký tự. Mật khẩu không hiển thị khi gõ. Sau đó khởi động lại:

npm start

Chỉ cập nhật tài khoản được chọn. Công cụ không xóa hoặc thay đổi VĐV, đội, lịch, tỷ số hay LIVE.

Quá trình này cần quyền truy cập máy chủ. Trang web không có nút đặt lại mật khẩu Admin công khai.

03 Nếu đang mở source trên máy tính

Ứng dụng cần chạy qua server. Từ thư mục source, dùng npm ci và npm start, rồi mở địa chỉ do terminal hiển thị. Không dùng file index.html mở trực tiếp để đăng nhập vào database.
